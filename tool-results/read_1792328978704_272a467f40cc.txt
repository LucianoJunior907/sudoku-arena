     1→# Sudoku Arena — Worklog
     2→
     3→## Project Status (Etapa 1 complete)
     4→
     5→Sudoku Arena is a single-route Next.js 16 App Router SPA (all "pages" are client-side views switched via a Zustand `route` state). Phase is **local-only**: no backend, no fake auth, no simulated multiplayer. Online-dependent features are clearly marked as "coming soon / needs backend".
     6→
     7→### Tech stack in use
     8→- Next.js 16 (App Router) + TypeScript 5
     9→- Tailwind CSS 4 + shadcn/ui (New York)
    10→- Zustand (app/game state) — already installed
    11→- next-themes (light/dark) — already installed
    12→- sonner (toasts)
    13→- lucide-react icons
    14→- Custom localStorage persistence layer (`src/lib/persistence/local-storage.ts`) isolated so it can be swapped for a remote implementation
    15→
    16→### Architecture laid out
    17→```
    18→src/
    19→  app/
    20→    layout.tsx          # Root layout + ThemeProvider + Sonner toaster + Providers
    21→    page.tsx            # Single route; view router driven by useAppStore.route
    22→    globals.css         # Sudoku Arena identity (emerald/teal + amber, NO blue/indigo)
    23→  lib/
    24→    i18n/               # translations (pt-BR, en) + useI18n/useT hooks (store-backed)
    25→    sudoku/             # engine.ts (generate/solve/validate/unique), types.ts, saved-game.ts
    26→    persistence/        # local-storage.ts (isolated, swappable)
    27→    progression/        # XP/levels/cosmetics/divisions
    28→    store/              # app-store.ts (Zustand: nav, settings, profile, stats, history, daily, streak, levelups)
    29→    contracts/          # persistence.ts (future backend interfaces: Auth/Profile/Match/Room/Ranking/XP/Friends/Chat/Daily)
    30→  components/
    31→    layout/             # AppShell, Sidebar, MobileNav (Sheet), OnboardingDialog, LevelUpToast, Providers, nav-config
    32→    views/              # LobbyView, SettingsView (+ placeholders for other views)
    33→    ui/                 # shadcn (existing)
    34→```
